개요

이 규격은 STM32 2026ydriver를 기준으로 합니다. AS와 FM은 송신 CAN ID만 구분하고, 모터 명령 데이터와 STM32 내부의 S-curve·전자브레이크·보호 기능은 공통으로 사용합니다.

멀티바이트 정수는 Big-Endian(MSB first)입니다. 구동 명령은 50ms 이하 간격으로 반복 송신하며, STM32 수신 타임아웃은 300ms입니다. 100ms 송신주기에서도 스케줄 오차로 허위 타임아웃이 발생하지 않도록 3배의 여유를 둡니다. 정상 구동 프레임 수신 후 타임아웃이 발생하면 FND와 UART 오류 필드에 코드 8을 표시합니다.

CAN ID

0x701AS 구동 · DLC 8
0x702FM 구동 · DLC 8
0x703공통 E-STOP · DLC 1
0x5B8STM32 상태 응답 · DLC 8

AS 하드웨어 모드에서는 0x701만 사용하고 FM 명령 0x702는 무시합니다. FM은 비-AS 상태에서 0x702를 사용합니다. 기존 장비 호환을 위한 비-AS 상태의 0x701/0x7C1 처리는 유지됩니다.

동일한 CAN 버스에서 AS와 FM 컨트롤러가 동시에 구동 명령을 송신하면 안 됩니다. 선택된 상위 제어기 한 대만 구동 프레임을 송신해야 합니다.

기존 AS ESP32 메뉴의 50/100/150/200은 송신 전에 ÷5 처리되어 실제 Byte2 10/20/30/40으로 전달됩니다. 따라서 STM32 가속시간은 각각 1/2/3/4초입니다. STM32는 실제 수신 Byte2만 제어 계산에 사용합니다.

좌우 목표값은 STM32에서 PWM으로 환산합니다. ESP32-P4는 장시간 가속 램프를 중복 적용하지 않고 목표 명령을 전송합니다.

FM 송신 예제

좌우 50%, 가속시간 5초, 배터리 설정 3, 기타 입력 없음:

ID = 0x702   DLC = 8
DATA = 01 F4 32 03 01 F4 00 00
Left0x01F4 = 500 = 50%
Accel0x32 = 50 = 5.0초
Battery0x03 = 설정 단계 3
Right0x01F4 = 500 = 50%

공통 비상정지

ID = 0x703   DLC = 1   DATA = FF

비상정지는 AS/FM 선택과 관계없이 STM32 비상정지 래치를 설정합니다. 일반 정지에는 E-STOP을 사용하지 않고, 좌우 구동 명령을 모두 0으로 송신합니다.

ESP32-P4 적용 규칙

  • 기존 0x100 구동 프레임을 0x702로 변경합니다.
  • 기존 0x000 E-STOP을 0x703:FF로 변경합니다.
  • 좌우 값은 RPM이 아닌 정규화된 -1000..1000 명령으로 전송합니다.
  • Follow 활성 중에는 새 거리 계산이 없어도 마지막 안전 명령을 50ms 이하 주기로 갱신합니다.
  • UWB 또는 ESP-NOW 데이터가 끊기면 즉시 0x703:FF를 송신하고 구동 프레임 송신을 중단합니다.
  • 재시작은 사용자의 명시적인 비상정지 해제와 Follow 재시작 조작 후에만 허용합니다.
