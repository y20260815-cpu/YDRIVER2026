1. 시스템 개요

YCB 듀얼 모터 드라이버는 STM32F103RBTx 마이크로컨트롤러를 기반으로 한 고성능 차량용 모터 제어 시스템입니다. 6-BLDC 모터를 정밀하게 제어하며, CAN 통신을 통한 차량 네트워크 연동이 가능합니다.

ℹ️ 주요 특징
• 듀얼 모터 독립 제어
• PID 기반 속도 제어
• CAN 2.0B 통신 지원
• ESP32 인터페이스 연동
• 다중 안전 기능 탑재

적용 분야

  • 전동 카트 (Electric Cart)
  • AGV (Automated Guided Vehicle)
  • 전동 휠체어
  • 소형 전기 자동차
  • 로봇 플랫폼

Watch Dog IWDG (Independent Watchdog)

항목 사양

제어 방식 6-Step Commutation
최대 RPM 3600 RPM (설정 가능)
PWM 분해능 0-850 (FET_MAX 기준)
제어 모드 속도 제어, 토크 제어

2.3 성능 사양

항목 성능
제어 주기 1ms (고속 루프), 10ms (저속 루프)

Slew Rate 0.1f/ms (가속도 제한)

EMB 해제 시간 200ms (소프트 스타트)
CAN 통신 속도 500 Kbps (표준)

4. 주요 기능

🎯 듀얼 모터 제어

두 개의 BLDC 모터를 독립적으로 제어합니다. 각 모터는 독립된 PID 컨트롤러로 정밀한 속도 제어가 가능합니다.

📡 CAN 통신

TJA1050 트랜시버를 통한 CAN 2.0B 통신을 지원합니다. VCU와의 실시간 데이터 교환이 가능합니다.

🔄 PID 속도 제어

Anti-windup 기능을 포함한 PID 제어로 안정적인 속도 제어를 실현합니다.

🛡️ 안전 기능

EMB(Emergency Brake), 과전류 보호, 온도 모니터링, Watchdog 등 다층 안전 시스템을 갖추고 있습니다.

⚡ Slew Rate 제한

급격한 가속/감속을 방지하여 부드러운 모터 제어를 제공합니다 (0.1f/ms).

💾 플래시 저장

설정값을 플래시 메모리에 저장하여 전원 차단 후에도 유지됩니다.

🌡️ 온도 감시

모터 및 FET 온도를 실시간 모니터링하여 과열을 방지합니다.

🔌 ESP32 연동

UART를 통해 ESP32와 통신하여 무선 제어 및 모니터링이 가능합니다.

4.1 PWM16 클래스 - 듀얼 모터 제어

PWM16 클래스는 시스템의 핵심으로 다음 기능을 제공합니다:

  • 듀얼 PID 제어: 각 모터에 독립적인 PID 컨트롤러
  • Anti-windup: 적분값 ±5000 제한으로 오버슈트 방지
  • Slew Rate 제한: 1ms 당 0.1f 변화율로 부드러운 제어
  • EMB 소프트 스타트: 긴급 정지 후 200ms 대기 및 점진 가속
  • BEMF 측정: 역기전력 측정으로 속도 피드백
  • 방향 전환 보호: 급격한 방향 전환 시 안전 처리
// PID 파라미터 예시 #define INTEGRAL_MAX_LIMIT 5000.0f // 적분 제한 #define SLEW_RATE_PER_MS 0.1f // 슬루레이트 #define FET_MAX 850 // PWM 최대값 #define EMB_RELEASE_DELAY_MS 200 // EMB 해제 대기

4.2 EPS (Electric Power Steering) 클래스

전동 파워 스티어링 기능을 제공합니다:

  • 조향각 계산 및 모터 방향 결정
  • 스위치 입력 기반 위치 제어
  • 좌/우 회전 및 정지 제어
  • 전진/후진 모드 지원

4.3 데이터 클래스 - 시스템 상태 관리

시스템의 전반적인 상태를 관리합니다:

  • 감속비 제어: 12단계 감속비 (역방향 포함)
  • 온도 모니터링: NTC 센서 기반 온도 측정
  • 전압/전류 감지: ADC 필터링 및 변환
  • CAN 데이터 패킹: RPM, 전류, 배터리, 온도 등 7바이트 패킹
  • 리프트/캐스터 제어: 차량 부가 기능 제어

6. 설정 및 사용법

6.1 초기 설정

Step 1: 하드웨어 연결

  1. 24V DC 전원을 메인 전원 단자에 연결합니다
  2. 두 개의 BLDC 모터를 PWM 출력 단자에 연결합니다
  3. CAN 버스를 TJA1050 단자에 연결합니다 (CAN_H, CAN_L, GND)
  4. ESP32 모듈을 UART3 단자에 연결합니다 (필요시)
  5. 조작 스위치 및 센서를 GPIO에 연결합니다
⚠️ 주의
전원을 인가하기 전에 모든 연결 상태를 점검하세요. 잘못된 연결은 장비 손상의 원인이 됩니다.

Step 2: 펌웨어 업로드

  1. STM32CubeIDE를 실행합니다
  2. 프로젝트를 엽니다 (ycb_dmdriver_103rbtx.ioc)
  3. 빌드합니다 (Project → Build All)
  4. 디버거를 연결합니다 (ST-Link V2 권장)
  5. 플래싱합니다 (Run → Debug 또는 Flash)
# 빌드 명령 (터미널) $ cd Debug $ make clean $ make all # 플래시 명령 (STM32_Programmer_CLI 사용) $ STM32_Programmer_CLI -c port=SWD -w ycb_dmdriver_103rbtx.elf

Step 3: PID 파라미터 설정

모터 특성에 맞게 PID 파라미터를 조정합니다:

// main.c 또는 설정 영역에서 PID_CONFIG pidCONF = { .Kp = 0.8f, // 비례 게인 .Ki = 0.001f, // 적분 게인 .Kd = 0.1f, // 미분 게인 .rpm_to_pwm_scale = 1.0f / 3600.0f // RPM → PWM 스케일 };

6.2 CAN 통신 설정

CAN ID 설정

방향 CAN ID 설명
수신 0x07B0 VCU로부터 제어 명령 수신
송신 0x07xx 상태 데이터 송신 (설정 가능)

CAN 메시지 포맷

// 송신 데이터 (7바이트) Byte 0-1: Motor1 RPM (int16_t) Byte 2-3: Motor2 RPM (int16_t) Byte 4: 전류 (uint8_t) Byte 5: 배터리 전압 / 10 (uint16_t, 하위) Byte 6: 배터리 전압 / 10 (상위 4비트) + Motor 온도 / 7 (하위 4비트)

6.3 운전 모드

기본 운전

  1. 전원을 인가합니다
  2. 부팅 완료를 기다립니다 (약 2초)
  3. 스로틀을 조작하여 모터를 제어합니다
  4. 방향 스위치로 전진/후진을 선택합니다

PID 캘리브레이션 모드

PID 제어를 비활성화하고 직접 PWM을 제어할 수 있습니다:

// disable_pid = 1로 설정 시 DoubleF_VALUE result = pPWM->pidCalibration( 1, // PID 비활성화 input_pwm, // 직접 입력 PWM pid_pwm // (무시됨) );

6.4 플래시 메모리 활용

설정값을 플래시에 저장하여 영구 보존합니다:

// 설정 저장 예시 CONFIG_TOTAL config; config.conf1.motor1_polarity = 0; config.conf1.motor2_polarity = 1; config.conf2.brake_rate = 50; // 플래시에 저장 stm32flash_write_config(&config); // 부팅 시 읽기 stm32flash_read_config(&config);

7. 안전 기능

🚨 EMB (Emergency Brake)

긴급 정지 신호 감지 시 즉시 모든 FET를 차단하고, 해제 후 200ms 대기 및 소프트 스타트를 수행합니다.

🌡️ 과열 보호

모터 및 FET 온도를 실시간 감시하여 설정 온도 초과 시 출력을 제한하거나 정지합니다.

⚡ 과전류 보호

ADC를 통해 전류를 측정하고 과전류 감지 시 PWM을 감소시킵니다.

🔋 저전압 보호

배터리 전압이 임계값 이하로 떨어지면 경고 메시지를 출력하고 출력을 제한합니다.

🐕 Watchdog

IWDG를 통해 시스템 정상 동작을 감시하고, 이상 발생 시 자동 리셋합니다.

🔄 방향 전환 보호

급격한 방향 전환 시 모터를 정지시킨 후 방향을 전환하여 기계적 손상을 방지합니다.

7.1 EMB 처리 시퀀스

EMB 발생 ↓ 모든 FET 즉시 차단 ↓ emb_release_delay = EMB_RELEASE_DELAY_TICK (50) emb_softstart_pwm = 0.0f ↓ EMB 해제 ↓ 200ms 대기 (20 × 10ms 틱) ↓ 소프트 스타트 (매 10ms마다 5% 증가) ↓ 정상 동작

7.2 Slew Rate 제한

급격한 가속을 방지하여 기계적 충격과 전기적 스파이크를 최소화합니다:

// 1ms 루프에서 실행 float delta = target_pwm - current_pwm; if (delta > SLEW_RATE_PER_MS) current_pwm += SLEW_RATE_PER_MS; // 0.1f/ms else if (delta < -SLEW_RATE_PER_MS) current_pwm -= SLEW_RATE_PER_MS; else current_pwm = target_pwm;

7.3 PID Anti-windup

적분값 포화를 방지하여 오버슈트와 불안정성을 제거합니다:

integral += error; // 적분 제한 if (integral > INTEGRAL_MAX_LIMIT) // 5000.0f integral = INTEGRAL_MAX_LIMIT; if (integral < -INTEGRAL_MAX_LIMIT) // -5000.0f integral = -INTEGRAL_MAX_LIMIT;

7.4 CAN Alive 체크

CAN 통신 단절을 감지하여 자동으로 안전 모드로 전환합니다:

#define CAN_ALIVE_TIMEOUT 10 // 100ms (10 × 10ms) if (can_timeout_counter++ > CAN_ALIVE_TIMEOUT) { // CAN 통신 끊김 - 안전 모드 DisableAllFETs_Dual(); cprintf(RED, "CAN Timeout!\n"); }

8. 문제 해결

8.1 모터가 작동하지 않음

증상 원인 해결 방법
전혀 움직이지 않음 전원 미공급 24V 전원 연결 확인
LED는 켜지나 모터 정지 EMB 활성화 EMB 신호 체크, 릴리즈 확인
한쪽만 작동 모터 연결 불량 PWM 케이블 및 전원선 점검
약하게만 작동 PWM 제한 설정 FET_MAX 값 확인 (850)

8.2 CAN 통신 문제

증상 원인 해결 방법
CAN Timeout 메시지 CAN 버스 단절 CAN_H, CAN_L 배선 점검
데이터 수신 안됨 CAN ID 불일치 RX_CANID = 0x07B0 확인
통신 불안정 종단 저항 누락 120Ω 종단 저항 설치
송신은 되나 수신 안됨 TJA1050 고장 TJA1050 칩 교체

8.3 제어 불안정

증상 원인 해결 방법
속도가 진동함 PID 게인 과다 Kp, Ki 값을 낮춤 (0.5~1.0)
목표 속도에 미달 PID 게인 부족 Kp 값을 높임 (0.8~1.5)
오버슈트 발생 적분 과다 Ki 값을 낮춤 (0.0001~0.001)
급격한 가속 Slew rate 과다 SLEW_RATE_PER_MS 감소 (0.05f)

8.4 온도 문제

증상 원인 해결 방법
FET 과열 과부하 운전 PWM 듀티 감소 또는 냉각 개선
모터 과열 연속 고부하 주기적 휴식, 방열 개선
온도 센서 오류 NTC 단선 온도 센서 배선 점검

8.5 디버그 방법

UART 디버그 메시지

UART3 (115200 baud)를 통해 디버그 정보를 출력할 수 있습니다:

// 컬러 출력 사용 cprintf(RED, "Error: %d\n", error_code); cprintf(GREEN, "Motor1 RPM: %d\n", rpm1); cprintf(BLUE, "PWM: %.2f\n", pwm_value); // 주요 색상 코드 // RESET, RED, GREEN, YELLOW, BLUE, MAGENTA, CYAN, WHITE

실시간 모니터링

// 10ms 루프에서 주요 변수 출력 if (ten_millisec_flag) { printf("M1: %4d RPM, PWM: %3d | ", rpm1, pwm1); printf("M2: %4d RPM, PWM: %3d | ", rpm2, pwm2); printf("Batt: %2.1fV, Temp: %2d°C\n", voltage, temperature); }

CAN 버스 스니핑

CAN 분석기를 사용하여 통신을 모니터링합니다:

  • CAN 속도: 500 Kbps
  • 수신 ID: 0x07B0
  • 데이터 길이: 8바이트
✅ 정상 동작 확인
• 부팅 시 "Boot OK" 메시지 출력
• CAN 통신이 10Hz로 수신됨
• 스로틀 입력에 모터가 즉시 반응
• 온도/전압이 정상 범위 내
• EMB 동작이 정상
