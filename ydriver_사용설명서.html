2026ydriver 사용설명서

STM32F103 기반 듀얼 DC 모터 드라이버 (리프트 / 방제차 / AS(아성) 공용) — 2026-09-05

1. 시스템 개요

2026ydriver는 STM32F103Rx(LQFP64) 기반의 듀얼 DC 모터 드라이버입니다. 로컬 입력(FNR 레버 + 스로틀)과 CAN 원격 명령을 모두 지원하며, 하나의 펌웨어로 리프트(삼부), 방제차(삼부), AS(아성 ESP32 인터페이스) 3종의 상위 컨트롤러와 호환됩니다.

항목내용
MCUSTM32F103RBT6 / RCT6 (LQFP64), 내부 RC(HSI) 기반 36MHz
모터 출력2채널 H-브리지 PWM (TIM2/TIM3), BEMF 기반 RPM 추정 + PID
배터리24V / 48V 자동 감지 (DC-Link 전압 기반, 보호 임계값 자동 설정)
CAN500 kbps, 트랜시버 SN65HVD232(3.3V)
표시1자리 FND (74HC595 구동, 에러코드/FNR 상태)
워치독IWDG 약 12.8초

AS 모드 점퍼 동작: 부팅 시 PA8을 풀다운 입력으로 판독합니다. 4-5번이 점퍼로 단락되어 있으면 PA8=High가 되어 AS-CAN 모드로 고정 진입하며, UART에 ### AS-CAN MODE (CON1 4-5 jumper detected) ###가 출력됩니다. 점퍼가 없으면 기존 자동 구분 모드로 동작합니다.

CAN 수신 중에는 로컬 FNR 레버 입력이 무시되며, CAN이 300ms(30틱) 이상 끊기면 일반 모드는 로컬 입력으로 자동 복귀합니다. 전환 시 마지막 CAN 버튼/토글 상태(스프레이 등)는 자동 클리어됩니다.

5. 전원 투입 시퀀스 (DC-Link)

  1. 부팅 → 전체 릴레이 OFF, AS 점퍼 판독
  2. MC2(프리차지) ON → 1초 대기 (DC-Link 커패시터 충전)
  3. MC1(메인) ON → 0.5초 대기 (스위칭 과도 안정화)
  4. DC-Link 전압 측정 → 24V/48V 모드 자동 감지, 보호 임계값 설정
  5. 션트 과전류 보호(ADC2 아날로그 워치독) 활성화
  6. SD(브리지 인에이블) High → 구동 준비 완료, FND에 0 표시

전원 차단(power_off) 시에는 SD 차단 → MC1·MC2 동시 개방 → 0.5초 후 전체 릴레이 OFF 순서입니다.

7.1.3 수신 후 데이터 흐름

0x701/0x7C1 수신(IRQ) → vcu_sdu 저장 + can_process_flag
  → 메인루프 can_process_routine()
      ├ 속도      → 명령 FIFO (50ms 소비, 램프/제동 공통 처리)
      ├ toggle/btn → inputRaw.io (리프트/스프레이 GPIO 제어)
      ├ emergency → HOLD_Emergency → power_off
      ├ 가속시간(byte2) → can_accel_rate,  감속시간(byte3) → can_decel_rpm_per_10ms
      └ alive 타이머 갱신 (300ms 두절 시 inputRaw.io 및 램프 계수 기본값 복원)

7.2 송신: VCU 상태 (0x5B8, 100ms 주기, DLC=8)

바이트내용비고
0~2RPM1(12bit) + RPM2(12bit) 패킹-3600~+3600 → 0~4095 인코딩, 전송 배율 1.667

아성 ESP32 인터페이스는 이 0x5B8 프레임을 수신하여 LCD에 전압·속도·온도를 표시합니다.

7.3 설정 프로토콜 (미지원)

0x700(설정 요청) / 0x708~0x70C(저장) / 0x5B0~0x5B7(응답) 프로토콜은 수신은 되나 본 펌웨어에서는 비활성화 상태입니다(SYSTEM_CONF 미사용). 해당 프레임 수신 시 무시 로그만 출력합니다.

8. 모터 명령 처리

  • 명령 FIFO: 로컬/CAN 입력 모두 동일한 큐로 투입, 50ms마다 1개 소비
  • 가감속 램프: 로그 스케일 가속, DC-Link 전압 감시 기반 회생 제한 감속
  • 방향 전환: 정지 확인 후 100ms 브리지 안정화 대기 후 역방향 인가
  • 단락 제동: 중립 진입 후 램프 완료 시 모터 회전 중에만 적용, DC-Link 과전압 시 강제 적용
  • FET 온도 디레이팅: 85°C부터 PWM 비례 축소, 100°C에서 차단

12. 트러블슈팅

증상점검 순서
메인 릴레이(MC1)가 안 붙음① FND 7/9 여부(보호 트립) ② ULN2003 입력·출력, COM(9번) 코일 전원 ③ PD2 핀 대GND 저항(정상: 수십 kΩ 이상) — 2Ω 수준이면 드라이버 또는 MCU 핀 단락
CAN 수신 안 됨① 마스터 비트레이트 500kbps 확인 ② CAN_H/L 배선·종단 ③ 트랜시버 U6 VCC(3.3V)·D(1번)·R(4번) 신호 ④ MCU 교체 이력이 있으면 PA11/PA12 납땜
수신은 되는데 마스터가 응답(0x5B8)을 못 받음이 노드의 TX 경로 점검: PA12 → U6 D(1번) 도통, ACK 펄스 유무 (수신만 되고 송신이 안 되면 버스 에러 카운터가 포화되어 결국 수신도 멈춤)
AS 모드로 진입 안 됨① CON1 4-5 점퍼 접촉 ② 부팅 로그에 AS-CAN MODE 표시 여부 ③ PA8 전압 (점퍼 시 3.3V)
CAN 두절 시 이상 거동일반 모드: 300ms 후 로컬 복귀가 정상. AS 모드: 정지 유지가 정상(로컬 레버 무반응은 의도된 안전 동작)
